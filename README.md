# utopia-hackathon-2026
AYNO team - U-topia Hackathon · "Cry for ur MOM"

Parents tap a button, the app records the baby's cry, the backend says why the baby cries, reads advice aloud, suggests a lullaby and hands off to the U-bot chatbot. See `docs/ARCHITECTURE.md`.

## Structure

```
index.html        shell (loads css/app.css + js/app.js as an ES module)
css/app.css       styles; colors are CSS variables in :root
js/               app.js (state, router, back), config.js, i18n.js (+ lang/th.js, lang/en.js),
                  api.js, recorder.js, activities.js, ubot.js, dom.js, ui.js, speech.js,
                  lullaby.js, upload.js, screens/*
assets/lullabies/ th-1.mp3 … en-3.mp3 (generated by scripts/generate_lullabies.py)
backend/ ml/ scripts/   FastAPI backend, training, lullaby generation
```

Buildless: no npm, no framework, no build step.

## Run locally

ES modules need an HTTP server (not `file://`):

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

Open http://127.0.0.1:4175. Use `127.0.0.1` or `localhost` (or HTTPS): browsers only allow the microphone on secure origins. If the microphone is unavailable, the app offers audio file upload instead.

## Mock mode vs backend

`API_BASE_URL` in `js/config.js` is `''` by default = **mock mode**: no network, `/analyze` returns canned results (confident, close, unsure, no_cry in rotation; a logged feed makes it confident), `/speak` returns no audio so only text is shown.

To use the real backend, set it and reload:

```js
export const API_BASE_URL = 'https://<your-space>.hf.space';
```

The backend must allow this origin via `ALLOWED_ORIGINS` (CORS).
